タクシー営業ノート プライバシーポリシー

タクシー営業ノートは、タクシードライバー本人が日報、売上、給与チェック、営業傾向を確認するためのローカル優先アプリです。

基本方針

本アプリは、個人の営業記録と自己分析を支援するためのツールです。正式な給与明細、税務書類、配車システム、会社公式レポートの代替ではありません。

保存する情報

本アプリは、次の情報をユーザーの端末内に保存することがあります。

  • 日別売上の入力内容
  • 給与チェック用の金額、歩率、基準歩率などの設定
  • 日報から取り込んだ乗車時刻、乗車エリア、運賃、乗車区分
  • 曜日、時間帯、エリア、地図表示のための集計値

運転者名、会社識別子、車両番号など、本人識別に強く関わる日報ヘッダー項目は分析用データとして保存しません。

利用目的

保存した情報は、締日にもとづく月次売上の計算、実質歩率の確認、曜日・時間帯・エリア・乗車区分別の営業傾向分析、地図表示のために使用します。

外部送信と第三者提供

現在のアプリはローカル優先です。保存した日報、売上、給与チェック、営業分析データをアプリ独自のサーバーへ送信する設計ではありません。また、ユーザーデータを販売したり、第三者へ提供したりする設計ではありません。

ユーザーが端末やOSの共有機能を使って明示的にデータを共有した場合、その共有先での取り扱いは共有先の規約やプライバシーポリシーに従います。

将来の変更

将来のバージョンでクラウド同期、アカウント機能、分析サービス、外部送信を追加する場合は、その機能を公開する前に本ポリシーを更新します。

Important notice

Taxi Business Notebook is a local-first personal work-analysis app. It stores daily sales, pay-check values, imported pickup records, and aggregated analysis values on the user's device. The current app does not send stored work-analysis data to an app-operated server and does not sell user data.
